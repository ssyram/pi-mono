# 全局正确性与完成门

核心推导、接口组合与 SCCO 在 [architecture.md](architecture.md)；逐函数分支和 pre→post 在 [detail.md](detail.md)。下列只集中记录实现时的直接功能证据与仍未闭合的事实，不是独立审查报告。

## 直接功能检查

| 输入/动作 | 必须观察 |
|---|---|
| 普通/具名 provider，同一 api＋端点而名称不同；profiles 安装/不安装 | route 相同，认证与显示各属当前 provider，无 profiles 文件/模块读取 |
| 三正式端点、同协议不同域、伪相似域、认证后的端点覆盖 | 只有三项 supported；陌生域 N/S；不得转发旧域凭据 |
| Codex primary 34%/604800 秒且 secondary=null；附加组/credit | 只显示真实窗口；附加额度分组、不补 5h/0%，非法字段 ERR |
| Z.AI 两区域 TOKENS_LIMIT/CREDIT_LIMIT/TIME_LIMIT、unit 3/4/5/6 | 已用百分比/次数与时间单位正确，区域不串；未知行标 partial 或 ERR |
| 国际精确业务失败＋同账号订阅列表空、国内同文案但无团队头、401/403 | 仅前两项同时成立的国际版隐藏；国内保持 ERR、401/403 为 AUTH；不能把业务失败当已用 100% |
| 同账号刷新成功/失败、首次失败、A→B 切换与密集 turn_end | 刷新中旧数不变；成功换新，失败旧数加 `(err)`；首次失败直接 ERR；A 值不挂到 B，仍保留单 job/60 秒限频 |
| shutdown/reload、非 TUI | 不遗留 timer/branch 监听/可见旧额度；非 TUI 不查额度 |
| session_start 已有 high 档、model_select/turn_end 未触发思考档位变更事件 | 右侧仍显示宿主 high；只有宿主当前值为 off 才显示 thinking off |
| 全 session entries 的 token/cache/cost；sub、context 阈值、费用缺席、窄屏、git branch、扩展 status | 用量为无 NAME 的短格式、在费用后取代 `(sub)`；详细重置/partial 不进入 footer；无用量时原 `(sub)` 条件保持，context/status 与数字不丢 |
| `/provider-usage`、`--all`、多个显式账号与未知名称 | 默认当前、全部可用去重、指定顺序分别输出详细结果；单项错误不吞后续；不借另一账号的认证，混用 `--all` 与名称报输入错误 |
| `/provider-usage ` 直接 Tab，以及第二、第三名称补全 | 候选来自当前可用 provider，补全后已有参数保持原样；其它命令的补全不受影响 |
| 三个目标服务分别真实查询 | Codex 原生/具名成功；两地区现有 key 已实测业务失败，不等于成功额度路径；国内团队上下文尚未取得 |

## 未闭合的真实边界

| 事项 | 当前证据与处理 |
|---|---|
| 非套餐归属 | 国际版精确业务失败且同账号订阅列表成功为空才隐藏；国内缺组织/项目头时同文案不够排除团队套餐，仍显示 ERR |
| Z.AI 两区域实测 | 两地区内置 key 业务失败且订阅列表为空，三个国际具名账号订阅列表也为空；仍无有效额度 JSON。`glm-000-gl` 无自身认证，国内团队头当前不存在；不能宣称成功路径已现场验收 |
| 国内团队套餐 | 按第三方实测协议实现 `?type=2`＋当前模型认证中的两个组织/项目头；当前账号没有这组头，也未验证团队成功响应。单缺一个头按 N/S，不伪装个人额度 |
| 宿主认证取消 | registry 解析无 signal；15 秒只保证 UI 停止等待与额度 fetch 取消，物理认证可能不结束；单物理 job 不堆积 |
| 纯插件 footer | 原生 `autoCompactionEnabled` 未向扩展暴露，故不显示 `(auto)`；setFooter 与其它自定义 footer 独占冲突，不能宣称完整保留其显示；需用户接受这些边界或另作设计裁决 |
| 同 id 重新登录 | 没有已证登录事件可触发即时刷新；下一次 turn_end/重新选择时更新，显示的是最近一次查询样本 |

实测证据只支持这些 key 在已查询服务面的状态，不支持把业务失败解释成 100% 用量；国内团队所需组织/项目上下文目前缺失。若服务协议变化，先更新拥有该契约的 D；本地测试不能代替未获得的 Z.AI 成功响应验收。独立 Hoare 推理仍未取得结果。
